# Overview

The widget **Kill Chain Phases** maps an IoC's activity to Lockheed Martin's kill chain stages: *Reconnaissance* → *Weaponization* → *Delivery* → *Exploitation* → *Installation* → *Command & Control* → *Actions*.

On Threat Intel Management's dashboard **Threat Landscape**, this widget also displays the count of IoC under each phase, in a tabular form.

For more information, refer to [Threat Intel Management](https://github.com/fortinet-fortisoar/solution-pack-threat-intel-management/blob/develop/README.md) solution pack documentation.

>[!Note]
>
>This widget is not available for customization.
